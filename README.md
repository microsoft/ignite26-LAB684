# [Microsoft Ignite 2026](https://ignite.microsoft.com)

## 🔥LAB684: Zero Trust for AI: Securing Agents in Your Organization

### Session description

Work the Zero Trust for AI Workshop hands-on. Baseline your environment, apply the new DevSecOps and AI memory guidance, and leave with a prioritized 12-24 month roadmap across identity, devices, data, network, AI and SecOps.

### 🚀 Getting started

#### In a guided session

If you're following along during a live session:

1. Open your assigned lab VM and sign in with the credentials provided by your lab platform.
2. Follow the [attendee instructions](instructions/README.md) with your instructor.
3. Use your assigned Cloud Admin account only when your instructor directs you to an admin portal.

#### On your own

If you're learning at your own pace:

1. Open the [attendee instructions](instructions/README.md). No repository clone or local installation is required to explore the Workshop and sample Assessment report.
2. Use Microsoft Edge to open the linked public resources.
3. Complete the tasks and record your findings. If you do not have an assigned lab environment, skip the Cloud Admin sign-in section.

### 🎯 Learning outcomes

By the end of this session, you will be able to:

- Navigate the Zero Trust Workshop and locate DevSecOps and AI memory guidance.
- Interpret sample Assessment findings using their results, supporting evidence, and recommended remediation.
- Use Assessment findings to prioritize Workshop recommendations and outline a security improvement roadmap.
